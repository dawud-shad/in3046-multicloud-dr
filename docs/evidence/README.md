# Evidence

Screenshots and outputs captured as we go, for the demo video and to show the project matches the proposal.

Capture: billing alarms and cost dashboards, failover test runs with timestamps, CI/CD pipeline runs, cloud console views, load-test graphs.

Each member explains their own part on camera, so capture your own evidence as you build it.

## Naming

One directory per capture session, `YYYY-MM-DD-topic/` - for example `2026-11-04-failover-gcp-down/`. Keep cloud console timestamps visible in screenshots: failover time is a marked result, not decoration, and the demo video needs it to be checkable.
